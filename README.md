# BulkyBook

An ASP.NET web application built as an educational project to learn and teach .NET 6 (updated to .NET 8), including Razor Pages.

## About The Project

A learning project following a complete web application structure, with features such as notifications (toastr) added progressively.

### Built With

- .NET 6 (updated to .NET 8)
- ASP.NET (Razor Pages)
